# Coding Agent Session Records

This directory is a required assignment deliverable.

For each meaningful Antigravity/coding-agent work session, save a sanitized transcript or session summary containing:
- Date/time and goal.
- Prompt/task given to the coding agent.
- Important files changed.
- Commands and tests run, with observed outcomes.
- Failed attempts, errors, and how they were corrected.
- Decisions or trade-offs made.
- Known limitations and next step.

Never store API keys, passwords, tokens, private credentials, or unnecessary personal data. Redact secrets before committing. Do not fabricate a transcript after the fact; record work as it happens. If the agent UI supports exporting a full transcript, preserve it after reviewing for secrets. Otherwise write an accurate session summary.
